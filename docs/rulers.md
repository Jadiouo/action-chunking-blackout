# 評估尺
- 母體：gym-aloha AlohaTransferCube-v0 初始條件（env seed）× 失明起點 t0 ~ U[50,250]（由 seed 決定，跨格配對）。
- 決策尺：成功率（max reward = 4），Wilson 95% CI；格間比較用配對 McNemar 精確檢定。
- 雜訊：策略推論 z=0，但**整個管線並非位元級確定性**（T1 實測，見下方「重跑雜訊」）：同 seed 重跑，成敗大多相同、偶爾翻轉。主要變異來自初始條件抽樣，所以「多 seed」= 增加初始條件數；另有小的重跑雜訊。每格 100 個初始條件（seed 0–99），比 pilot 的 50 多一倍。
- 門檻：100 次時 p≈0.8 的 CI 半寬約 ±0.08；差距 < 0.1 且 McNemar p > 0.05 視為無差異。
- 有效 N：每格 100 個獨立初始條件。

## 重跑雜訊（T1/T2 實測，2026-11-03）
- 同設定（n=25, L=0, seed 0–4）跑兩次：成敗與 max_reward 5/5 相同，但 3/5 episode 的步數或重規劃次數不同（`results/n1_diagnosis.md` 第 1 節）。
- 來源定位：策略前向（同輸入 20 次）完全相同、`reset(seed)` 完全相同、重播同一串動作時 agent_pos 完全相同，但渲染影像最大差 1 個灰階。推論：渲染的 ±1 灰階差異經閉迴路放大。
- 規模：pilot 的 900 個 episode（seed 0–49，18 格）在完整網格（T2）重跑，env seed 與 t0 完全相同：成敗不同 8/900（0.9%），max_reward 不同 35/900（3.9%），步數不同 141/900。清單：`results/pilot_vs_full_mismatch.csv`。
- 翻轉集中在中等成功率的格（n=10、L=0：2/50；n=10、L=50、freeze：2/50；n=25、L=50、black：3/50；n=50、L=50、black：1/50）；其餘 14 格 0 翻轉。格內成功數最大差 3/50（n=25、L=50、black：15 → 12）。
- 對決策的影響：單格 100 次的 CI 半寬 ±0.08–0.10 遠大於重跑雜訊（格內成功數差 ≤ 3/50 = 0.06）；門檻「差距 < 0.1」仍適用，但小於 0.05 的差距不可解讀。報告中的 pilot 與完整網格不應混用同一個 episode 當成「同一次量測」，以完整網格為準。
- 排除「執行緒數造成差異」：完整網格的工作使用 `OMP_NUM_THREADS=2`（pilot 為預設，因機器 CPU 滿載時預設值慢 4 倍以上）。把 8 個翻轉 episode 用預設執行緒各重跑 3 次（`results/parts/noise_repeat.csv`）：同一 episode 的 3 次結果彼此也會不同（例：n=10、L=0、seed 5 為 0/0/1；seed 30 為 1/0/0；n=25、L=50、black、seed 39 為 0/1/0；n=50、L=50、black、seed 15 為 0/0/1），所以翻轉是重跑本身的雜訊，不能歸因於執行緒設定；但也沒有做「兩種執行緒設定各大量重跑」的對照，故不能排除它有微小影響。
- 另有 3 個 episode（n=25、L=50、black、seed 41、43，及 n=10、L=50、freeze 的 seed 5、18）在重跑中多半維持與完整網格相同的結果，表示這些是「接近門檻」的初始條件，雜訊只在這類 episode 才改變結果。
