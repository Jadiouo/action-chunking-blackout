## 2. 邊界假說：成功率 ~ k（失明期間重規劃次數）

**用詞與設計**：k = 欄位 `replans_in_blackout`，是失明窗口 [t0, t0+L) 內發生的重規劃次數。固定 n 時重規劃發生在 t = 0, n, 2n, …，所以 k 由 n、L 與 t0 對 chunk 邊界的相位決定，是**中介變數，不是被獨立操縱的變因**；每個 episode 的 (n, L, t0) 決定它。單一 k 的效果只能在「同 (n, L) 格內，t0 相位造成 k 不同」的準自然實驗，或迴歸控制 L、n 之後觀察。

**樣本與排除**

- 迴歸只用固定 n ∈ {10, 25, 50, 100}、L ∈ {10, 25, 50, 100}（每個 mode 1600 個 episode，配對於 100 個初始條件）。
- **排除 n=1**：n=1 全部 900 個 episode 成功 0 次（失明格 800 個也是 0 次，只因 T1 的停滯與 k 無關），結果變數沒有變異，邏輯斯迴歸完全分離、係數發散，無法估計。
- **排除 TE**：TE 每步重規劃（失明格 k ≈ L，平均 45.8），而且是 temporal ensembling 的另一種機制（不是改 n），成功率 0.59 與「k 大必失敗」並不相容，混入同一個線性 k 項會改變 k 的意義；單獨列在主表。
- k 有 7 個不同值（0, 1, 2, 3, 4, 5, 10）；k 與 log2(n) 的相關係數 -0.62、k 與 L 的相關係數 0.57（共線性：k ≈ L/n），所以必須看控制後的係數。
- 紀錄的 k 與排程 k_sched（由 t0, L, n 算出，不受成敗影響）一致比例 0.987；不一致的 41 列全部是成功 episode（成功比例 1.00，k 比 k_sched 少 1.05）。原因：成功即結束 episode，失明結束前就成功的 episode 少算了之後的重規劃（結果截斷 k）。因此另用 k_sched 做敏感度。

### 2.2 讀表（事實／推論分開）

**事實**

- n=100、L=50：黑畫面 k=0 為 36/43，k≥1 為 3/57；凍結 k=0 為 36/43，k≥1 為 41/57。同一個 k≥1 條件下，黑畫面幾乎全敗而凍結多數成功，所以傷害不在「重規劃發生」本身，而在重規劃**吃進了什麼影像**。
- black：單變數 k 係數 -1.339（cluster SE 0.220，p=1.1e-09，N=1600）；控制 L 與 log2 n 後 k 係數 -1.156（SE 0.281，p=3.9e-05，仍顯著）；再加 t0 分段後 -1.277（SE 0.320，p=6.5e-05）；二元 1{k>0} 控制後 -2.477（SE 0.294，p=3.9e-17）。

**推論**

- 黑畫面：控制 L 與 n 後，每多一次失明期間重規劃 logit 變動 -1.16（勝算比 0.31），k 在控制 L 與 n 後仍有解釋力；凍結：-0.18（勝算比 0.84，p=0.002），仍顯著但幅度遠小於黑畫面。這支持「失明期間的重規劃是主要傷害機制，且壞到什麼程度取決於影像內容」，但 k 不是被操縱的變因，且與 t0 糾纏，只能稱為與機制一致的關聯證據；oracle（第 4 節）才是對 k 的介入。

### 2.3 限制

- k 是 (n, L, t0) 的函數；表中 k=0 與 k≥1 的 episode 失明落在任務的不同階段（t0 不同），G 模型的 t0 分段只做粗略控制。
- 記錄的 k 在成功時被截斷（成功 episode 提前結束），這會讓 k 與成功呈人為的負相關；k_sched 模型（S）不受此影響，結論是否一致見完整係數表。
- 各格共用同一批初始條件，已用 cluster-robust SE，但只有 100 個 cluster；AIC 與 MH p 未校正此相依。
- L 與 k 在 n 固定時幾乎共線，k 的獨立效果主要靠 n=50、100 的格內相位變異辨識。

## 4. 區分性分析：oracle 的改善來自「失明期間不吃壞觀測」，還是「等同較大 n」？

**oracle 的定義**：被**告知**失明區間的規則（失明期間不重規劃、沿用手上 chunk 剩餘動作，chunk 用完才被迫重規劃），不是策略自己察覺到影像壞掉；它是上限／介入實驗，不是可實作的方法。

兩個假說的可檢驗預測：
- H_blind（不吃壞觀測）：oracle 相對固定 n 的增益，集中在「固定 n 會在失明中重規劃」的 episode；在固定 n 本來就沒碰到壞影像的 episode 上增益應接近 0。
- H_n（等同較大 n）：增益與固定 n 是否碰到壞影像無關，且 oracle(n) 應與固定 n=100 相近（因為少重規劃 ≈ 大 n）。

### 4.4 結論

**事實**

- black（L=10/25/50 合併，fixed-100→oracle）：oracle n=25：k100=0 子集 0.81→0.85（+0.03，N=201），k100≥1 子集 0.05→0.75（+0.70，N=99）；oracle n=50：k100=0 子集 0.81→0.89（+0.07，N=201），k100≥1 子集 0.05→0.87（+0.82，N=99）。
- freeze（L=10/25/50 合併，fixed-100→oracle）：oracle n=25：k100=0 子集 0.81→0.85（+0.04，N=201），k100≥1 子集 0.78→0.75（-0.03，N=99）；oracle n=50：k100=0 子集 0.81→0.89（+0.07，N=201），k100≥1 子集 0.78→0.86（+0.08，N=99）。
- oracle(n) 對 fixed n=100（L=50）：black n=25：84 對 39；black n=50：85 對 39；freeze n=25：84 對 77；freeze n=50：85 對 77。
- oracle(n) 與同 n 無失明（L=0）：black n=25、L=50：oracle 84 對 L=0 80（Δ=+0.04）；black n=50、L=50：oracle 85 對 L=0 91（Δ=-0.06）；freeze n=25、L=50：oracle 84 對 L=0 80（Δ=+0.04）；freeze n=50、L=50：oracle 85 對 L=0 91（Δ=-0.06）。
- forced=0 組在 L=100 的成功率高，但 forced=0 的 episode 中有 100% 在失明結束前（steps < t0+L）就已結束（截斷），故不採為證據（見 4.3）。

**推論**

- 黑畫面：oracle 相對 fixed-100 的增益在「fixed-100 會在失明中重規劃」的子集為平均 +0.76，在「不會」的子集為 +0.05。增益集中在會吃壞影像的子集，在固定 n 本來就沒吃到壞影像的子集上接近 0 或為負，**與 H_blind 一致、不支持 H_n**。
- 凍結：增益在會重規劃的子集為平均 +0.03、不會的子集 +0.06；兩者都小，因為凍結影像（最後一張好影像）本來就不傷，fixed-100 在 k100≥1 子集仍有 0.78。
- 固定 n=100 在「失明中沒有重規劃」的子集（k100=0，L=10/25/50 合併）成功率 0.81，與其 L=0 的 0.80 相當；有重規劃的子集黑畫面 0.05、凍結 0.78。
- oracle(n=25/50) 在 L ≤ 50 與同 n 無失明（L=0）的差距（Δ，oracle − L=0）範圍：black n=25：-0.01 至 +0.04；black n=50：-0.06 至 +0.00；freeze n=25：-0.01 至 +0.04；freeze n=50：-0.06 至 +0.00。即只要失明期間不重規劃，失明的成本在這個範圍內大致消失；這同時說明增益不是「n 變大」造成：fixed n=100 在 L=50 黑畫面只有 0.39、凍結 0.77（主表）。
- oracle 在 L=100 並不是「完全不吃壞影像」：chunk（100 步）撐不過整段失明時被迫重規劃（forced），這時用的是過期影像；L=100 時 oracle 成功率明顯低於 L ≤ 50（見 4.1 表），與此一致，但無法排除 L=100 本身更難。

**限制**

- oracle 與 fixed 用不同執行迴圈（見檔頭說明）、各帶重跑雜訊；差距小於 0.05 的格不可解讀。
- k100 分層依 t0 相位，t0 也決定失明落在任務哪一階段，子集間任務難度並不相同。
- 沒有 oracle(n=100)（最直接的「相同 n、只改是否吃壞影像」對照）；k100=0 子集的 fixed-100 是最接近的代用品，但它的子集是事後依 t0 選出，不是隨機分派。
- forced 比較只能在 L=100 內做、為 unpaired，且受截斷影響（見 4.3）。

## 7. 重跑雜訊與可解讀性

依 docs/rulers.md：同設定重跑成敗約 1% 翻轉，單格成功數最大差 3/50，故**差距 < 0.05 一律標「不可解讀」**；差距 < 0.10 且 p > 0.05 為「無差異」。本報告的配對比較表（3.1–3.3、4.1、4.2、5.3）共 196 個檢定，其中 |Δ|<0.05 者 79 個，已在判讀欄標出，不應據此下結論。第 1 節與圖中的單格成功率各帶 Wilson 95% CI（n=100 時半寬約 ±0.08–0.10）。

## 8. 整體限制

- 單一 checkpoint、單一任務（Transfer Cube）、模擬環境；每格 100 個初始條件，CI 半寬 ±0.08–0.10。
- 格間共用同一批初始條件與 t0，格間比較已用配對或 cluster-robust SE，但不是獨立樣本；跨格合併的 p 值只作描述。
- 整條管線非位元級確定性（docs/rulers.md），oracle 與 proprio 另用自寫執行迴圈。
- k 與 t0 糾纏；oracle 是被告知失明區間的上限，不是可部署的方法。
