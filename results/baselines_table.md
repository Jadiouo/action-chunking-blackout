# P3 文獻方法對照：Median TE、CARE 式觸發 vs fixed n／oracle／detect（Transfer Cube，seeds 0–99 配對）

本檔由 `code/make_baselines.py` 從 `results/baselines.csv` 產生。方法與參數見 `docs/p2p3_notes.md`、`docs/baselines_spec.md`。R = 該方法失明成功率 / 該方法自己的乾淨（L=0）成功率；ρ = (方法 − fixed n)/(乾淨 fixed n − fixed n)，以 fixed n=50（乾淨最佳）與 fixed n=100（ACT 預設）為參照，分母 < 0.10 記 n/r。McNemar 精確檢定，Holm 校正家族見腳本註解；差距 < 0.05 標 noise，不做解讀。

CARE 的 τ（乾淨 seeds 100–119 校準，目標乾淨平均執行長度 0.6·H_max=30 為主）：main=0.3，low(0.4·H_max)=0.18，high(0.8·H_max)=0.5。

## 成功率表（每格成功數/N = 率 [Wilson 95%]；R；ρ）

R 的分母：n 規則（fixed／oracle／detect／generic）用同 n 的乾淨 fixed 成功率（full_grid.csv L=0）；TE／CARE 用自己的乾淨（L=0）成功率。ρ：n 規則用同 n 的 fixed（同格同 n）；Median／Mean TE 與 CARE 沒有 n，改對 fixed n=50（乾淨最佳）與 fixed n=100（ACT 預設）各算一個。`fixed_grid_*`／`meanTE_grid_*` 是 full_grid.csv（run_grid.py）的舊列，僅供對照、不做檢定（與同迴圈列逐 episode 約 6–14% 翻轉，見 p2p3_notes.md）。
