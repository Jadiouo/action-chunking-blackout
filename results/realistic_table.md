# P2 合成相機損壞（Transfer Cube）：gaussian noise、部分遮擋、延遲、間歇閃斷

本檔由 `code/make_realistic.py` 從 `results/realistic.csv` 產生（程式 `code/run_p2p3.py`、`code/corrupt.py`；強度為我們自訂，見 `docs/p2p3_notes.md`）。損壞只作用在失明窗 [t0, t0+L)，窗外立即回到當前真影像；env seed 與 t0 與 T2 同（配對）。R = 失明下成功率 / 同 n 乾淨（full_grid.csv，L=0，同 seeds）成功率；ρ = (規則 − fixed)/(乾淨 − fixed)，分母 < 0.10 記 n/r（不報）；方括號為 seed 的 bootstrap 95% CI（4000 次）。ρ 後的 * 表示 bootstrap 有 >5% 的抽樣分母掉到 0.10 以下。McNemar 為精確二項檢定（規則單贏／fixed 單贏），p 為 Holm 校正後（家族＝本檔主表所有規則對 fixed 的比較）。差距 < 0.05 標 noise，不做解讀。
